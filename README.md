# البصمة الذكية — Smart Touch POS

نظام إدارة نقاط البيع المتكامل المبني على Electron + React + SQLite.

---

## المميزات الرئيسية

- **نقطة بيع كاملة** — منتجات، تعديلات، باركود، متغيرات، طلبات آجلة
- **إدارة المخزون** — تاريخ الحركة، تعديلات يدوية، تنبيهات نفاد المخزون
- **أوامر الشراء** — موردون، استلام مخزون، محاسبة ضريبة المدخلات
- **إدارة العملاء وبرنامج الولاء** — تصنيفات برونزي / فضي / ذهبي
- **محاسبة مزدوجة القيد** — مخطط حسابات، دفتر أستاذ، ميزان مراجعة
- **تقارير مالية** — إيرادات، تكلفة البضاعة المباعة، مصروفات، أرباح
- **تقرير ضريبة القيمة المضافة** — مخرجات / مدخلات / صافي
- **فواتير ZATCA** — TLV QR Code، دعم الفاتورة المبسطة والضريبية (B2C / B2B)
- **إدارة الموظفين والورديات** — أرقام سرية مشفرة، صلاحيات، تقرير Z
- **نظام ترخيص** — مفاتيح HMAC مرتبطة بالجهاز مع تاريخ انتهاء
- **نسخ احتياطي تلقائي** — كل 12 ساعة، الاحتفاظ بآخر 7 نسخ

## تشغيل بيئة التطوير

```bash
npm install
npm run start        # يشغّل Vite + Electron معاً
```

---

## بناء المثبّت

```bash
npm run dist         # ينتج ملف portable EXE في dist-electron/
```

> تأكد من وجود `public/icon.ico` قبل البناء.

---

## هيكل المشروع

```
electron/
  main.cjs          ← نقطة دخول Electron، معالجات IPC
  database.cjs      ← طبقة SQLite الكاملة (better-sqlite3)
  preload.cjs       ← جسر الـ contextBridge
  zatca_utils.cjs   ← TLV / UBL XML / UUID / Hash

src/
  pages/            ← صفحات React (POS, Dashboard, Reports, ...)
  components/       ← مكونات مشتركة (AppLayout, SecurityGuard, ...)
  store/            ← Zustand stores (auth, cart)
  utils/            ← مولّد QR Code

public/
  icon.ico          ← أيقونة التطبيق
```

## قاعدة البيانات

يُحفظ ملف `pos_data.db` في مجلد بيانات المستخدم الخاص بالتطبيق:

```
%APPDATA%\البصمة الذكية\pos_data.db
```

لا يُضاف الملف إلى Git (مُدرج في `.gitignore`).
